## 👨‍💻 About Me

I'm **Ali Haider**, a **Full-Stack Web Developer and Backend Developer** with **3+ years of professional experience** building web applications, APIs, dashboards, and business-focused software systems.

## 🏗️ Full-Stack Architecture Mindset

I prefer building applications with clear separation between the **frontend, API layer, business logic, database and infrastructure** instead of putting everything into a single controller or component.

```text
                    ┌─────────────────────┐
                    │      Frontend       │
                    │ Vue / Quasar / React│
                    └──────────┬──────────┘
                               │
                               ▼
                    ┌─────────────────────┐
                    │      API Layer      │
                    │  REST / GraphQL     │
                    └──────────┬──────────┘
                               │
                               ▼
                    ┌─────────────────────┐
                    │   Business Logic    │
                    │      Services       │
                    └──────────┬──────────┘
                               │
                 ┌─────────────┼─────────────┐
                 ▼             ▼             ▼
          ┌─────────────┐ ┌─────────────┐ ┌─────────────┐
          │  Database   │ │ External    │ │ Queues /    │
          │    MySQL    │ │ APIs        │ │ Jobs/Events │
          └─────────────┘ └─────────────┘ └─────────────┘
                               │
                               ▼
                    ┌─────────────────────┐
                    │ Docker / AWS / K8s  │
                    │ Deployment Layer    │
                    └─────────────────────┘
```
